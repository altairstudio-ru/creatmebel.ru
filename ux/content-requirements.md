# Креат Мебель v2.0 — Требования к контенту

**Дата:** 11.09.2026 | **Автор:** ArchitectUX | **Назначение:** для копирайтера и наполнения прототипа

**Тон голоса:** тёплый, экспертный, без канцелярита и «уникальных предложений». Говорим как мастер с клиентом: конкретно, по-человечески, с цифрами.
**Принципы:**
1. Цифры в каждом обещании: «15 минут», «5–7 дней», «18 мес. гарантии».
2. Цена и срок — раньше, чем рассказы о себе.
3. «Всё включено» всегда расшифровывается (что именно включено).
4. Не пишем «от 500 ₽», если реальная вилка другая.
5. Москва → слово «Москва» в H1 и SEO-заголовках (локальный запрос из старого сайта).

**Термины, которые используем:** «всё включено», «просчёт по вашим размерам», «прозрачное производство», «трекинг заказа», «рассрочка 0-0-4».

## 3. Карточка товара

| Блок | Требования к контенту |
|---|---|
| Название | Модель + тип: «Диван угловой “Ричардс”». Старый сайт: артикул — сохранить («Артикул: R-452»). |
| Цена «всё включено» | Одна крупная цена. Кнопка/строка «Что входит»: ткань, каркас, доставка по Москве, подъём на этаж (лифт), сборка, гарантия. Без «от». |
| Сроки | «Готовность 5–7 дней», «Доставка +1–2 дня». Для корпусной: «под размер 10–14 дней». |
| Рассрочка | «Рассрочка 0-0-4: от 3 767 ₽/мес» (цена/4). Банки-партнёры: Т-Банк, Сбер (уточнить). |
| Опции | Ткань (каталог с фото и ценой доплаты «+0 ₽ / +2 400 ₽»), механизм, размер (если есть). При изменении цена и срок обновляются. |
| Описание | 3–5 абзацев: для кого модель (гостиная одной комнаты, небольшая квартира), что в конструкции, какая ткань/каркас/наполнитель. |
| Размеры | Таблица: Ш×Г×В, размер спального места, высота сиденья, глубина сиденья. Схема с габаритами. «Не влезает по размеру? Сделаем диван под вашу нишу — [рассчитать]». |
| Материалы | Каркас (массив/фанера/ЛДСП + класс), ткань (износостойкость, тесты Мартиндейла), наполнитель (ППУ плотность), механизм (нагрузка, гарантия). |
| Доставка (таб) | Та же честная таблица, что на странице доставки (включено/оплачивается). |
| Отзывы | Рейтинг, число отзывов, фильтр по «с фото», сортировка «новые/полезные». Форма отзыва: оценка, текст, фото. Модерация — 24 ч. |
| Похожие | «С этим смотрят» — 4 модели того же типа, по возрастанию цены. |
| Гарантия | «Гарантия 18 месяцев. Возврат в течение 7 дней, если товар не подошёл» (ссылка на условия). |
| SEO | Уникальный title: «Купить диван угловой “Ричардс” в Москве — цена 45 200 ₽ всё включено | Креат Мебель». Микроразметка Product + Offer + AggregateRating. |

## 7. Сквозные требования (все страницы)

| Элемент | Требование |
|---|---|
| Телефон | Один формат в дизайн-токене; кликабелен на mobile (tel:). |
| Числа | Формат цен: «45 200 ₽» (не «45,200»). Сроки: «5–7 дней». Размеры: «Ш 220 × Г 95 × В 85 см». |
| Разделители | Не использовать «от» без вилки. «Включено» помечать оливковым цветом. |
| CTA-тексты | Глаголы: «Смотреть каталог», «Добавить в корзину», «Заказать просчёт», «Получить расчёт», «Оформить заказ», «Перезвоните мне». Без «Узнать подробнее» (кликбейт). |
| Заголовки H2 | Строить по схеме: польза или вопрос («Честные тарифы без сюрпризов», «Как мы делаем мебель»). |
| Формы | Подпись над каждым полем, placeholder только как пример («+7 (900) 000-00-00»), кнопка внизу формы, согласие на обработку данных чекбоксом. |
| SEO base | Для каждой страницы: уникальный title ≤60 симв, description 140–160 симв, H1 один, микроразметка (Organization, Product, BreadcrumbList, FAQPage). |
| Доступность | Alt-тексты к фото товара («Диван угловой Ричардс, ткань велюр, цвет песочный»), подписи к иконкам. |

## 8. Открытые вопросы по контенту (нужно у заказчика)

- [ ] Точные тарифы за МКАД, подъём без лифта, сборка (влияют на страницу доставки и карточку).
- [ ] Цифры для блока «о нас»: количество заказов за всё время, % в срок, % брака.
- [ ] Адрес производства/шоурума в Москве.
- [ ] Реквизиты юрлица для страницы контактов.
- [ ] Банки-партнёры по рассрочке.
- [ ] Условия «рассрочки 0-0-4»: мин. сумма заказа, срок 4 месяца, штрафы при просрочке.
- [ ] Фото/видео материалов: цех, мастера, видео-тур (есть ли? можно ли снимать?).
