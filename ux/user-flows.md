# Креат Мебель v2.0 — User Flows (сценарии пользователя)

**Дата:** 11.09.2026 | **Автор:** ArchitectUX | **Формат:** схемы + шаги для desktop и mobile

## Сценарий A. «Купить диван» (транзакционный, 80% трафика)

### A.1 Схема (общая)

```
[ВХОД]                    [ВЫБОР]                            [ПОКУПКА]
Главная/Hаталог/Поиск  →  Каталог → Диваны                →  Карточка товара
                              │  фильтры: тип, цена,           │ галерея, цена, опции
                              │  размер, механизм, ткань       │ размеры, ткань, сроки
                              ▼                                ▼
                      Карточка товара ───────────────►   Добавить в корзину
                      (нет подходящего?)                     │
                              │                              ▼
                              ▼                         Корзина → Оформление
                      «Мебель по вашим размерам»          │ без регистрации
                      (сценарий Б)                        │ телефон / СМС-код
                                                          ▼
                                                   Доставка: дата, адрес
                                                   + подъём + сборка (галочки)
                                                          ▼
                                                   Оплата: карта/СБП/
                                                   рассрочка 0-0-4/при получении
                                                          ▼
                                                   Подтверждение + СМС
                                                   → трекинг статуса
```

### A.2 Desktop — пошаговый сценарий

| # | Шаг | Экран/действие | UX-требование |
|---|-----|----------------|---------------|
| 1 | Вход | Главная → блок «Каталог» → карточка «Диваны» (или mega-menu) | Один клик от героя до списка диванов; в hero сразу CTA «Смотреть диваны» |
| 2 | Сузить выбор | Каталог → вкладка «Мягкая мебель» → подкатегория «Диваны», фильтры: тип (прямой/угловой/детский), цена до 60 000 ₽, ткань | Фильтры видны без скролла (боковая панель или верхняя строка чипов); результат мгновенно обновляется; счётчик: «Найдено 14 диванов» |
| 3 | Изучить товар | Открыть диван «Ричардс» | Галерея фото/видео; цена крупно; блок «Всё включено» раскрывает состав цены |
| 4 | Кастомизация | Выбрать ткань, механизм, размер | Цена и срок **пересчитываются мгновенно** (главная боль — непрозрачность) |
| 5 | Убедиться | Скролл: размеры → материалы → фото в интерьере → отзывы → гарантия 18 мес | Блоки снимают сомнения: «впишется ли», «не развалится ли» |
| 6 | Купить | Кнопка «Добавить в корзину» → корзина → «Оформить заказ» | Без регистрации: телефон + код из СМС, имя опционально |
| 7 | Доставка | Выбор даты привоза, адрес; галочки «подъём на этаж» и «сборка» | Стоимость видна **до** ввода данных (честные тарифы «всё включено»); если подъём/сборка входят — показать «Включено бесплатно» |
| 8 | Оплата | Карта / СБП / рассрочка 0-0-4 / при получении | Рассрочка — 1 тап «Оформить в рассрочку», расчёт показывается сразу |
| 9 | Финал | Экран «Спасибо»: номер заказа, срок производства/доставки, СМС-ссылка на трекинг | Обещание сроков + трекинг = вторая по силе боль, закрываем сразу |

### A.3 Mobile — отличия

1. **Вход:** нижний таб-бар «Каталог» → горизонтальные чипы подкатегорий. B
2. **Фильтры:** кнопка «Фильтры (2)» открывает нижний шторный экран (sheet); применение через «Показать 14 товаров».
3. **Сравнение:** свайп по карточкам; карточка — вертикальная (фото сверху, цена и сроки снизу).
4. **Карточка товара:** галерея 100% ширины экрана, свайп-навигация; опции — чипы; снизу **sticky-панель**: цена + кнопка «Добавить в корзину» (всегда видна при скролле).
5. **Оформление:** один экран с разделами-аккордеонами («Доставка», «Оплата») вместо многошаговой формы; поля: телефон → СМС-код → адрес → кнопка «Заказать».
6. **Точки сомнений:** кнопка «Задать вопрос» и звонок в один тап в той же sticky-панели.

### A.4 Состояния и риски сценария A

| Состояние | UX-поведение |
|---|---|
| Пустой результат фильтра | «Под такие параметры ничего нет» + предложить: сбросить фильтры / похожие модели / «Мебель по вашим размерам — сделаем точно под вас» |
| Товар закончился | Карточка: кнопка «Сообщить о поступлении» (email/телефон) + «Похожие модели в наличии» |
| Ошибка ввода в оформлении | Поле подсвечивается, текст-подсказка «Например: +7 900 000-00-00»; кнопка не блокируется без причины, ошибка объясняет как исправить |
| Загрузка | Скелетоны карточек (не спиннер); в каталоге из 60 товаров — ленивая подгрузка «Показать ещё» |
| Hover (desktop) | Карточка: приподнимается, появляется кнопка «В корзину»; фото меняется на второе (вид сверху/в интерьере) |

**Метрики:** конверсия визит→заказ ≥ 1,5%; время до оформления < 4 мин (desktop); доля мобильного ≥ 60%; отказы на шаге «Доставка» < 25%.

## Сценарий Б. «Заказать просчёт по своим размерам» (високонверсионный для корпусной мебели)

### Б.1 Схема (общая)

```
[ВХОД: 4 точки]
mega-menu / главная баннер / карточка товара / таб-бар
        │
        ▼
[ФОРМА «Мебель по вашим размерам»]
  шаг 1: тип мебели (чипы) + размеры (ширина/высота/глубина)
  шаг 2: прикрепить фото/план комнаты (опционально, но подсказываем)
  шаг 3: имя/телефон (+ город = Москва по умолчанию)
        │
        ▼
[ПОДТВЕРЖДЕНИЕ]
  «Заявка принята. Перезвоним за 15 минут (в рабочее время 9:00–20:00)»
  номер обращения + СМС-дубль
        │
        ▼
[ДИАЛОГ С МЕНЕДЖЕРОМ]                    [FALLBACK]
  уточнение размеров, материалов,   ──►   письмо на info@creatmebel.ru
  сроков, сметы в WhatsApp/звонок         с тем же TЗ (если не дозвонились)
        │
        ▼
[ПРОСЧЁТ]
  фиксированное КП: цена «всё включено»,
  сроки по этапам (проект → производство → доставка),
  подтверждение в WhatsApp/почте в течение 2 часов
```

### Б.2 Desktop — пошаговый сценарий

| # | Шаг | UX-требование |
|---|-----|---------------|
| 1 | Вход | Из mega-menu (строка-баннер) или баннера на главной. Заголовок: «Мебель по вашим размерам» + подзаголовок «Рассчитаем бесплатно за 15 минут, даже если у вас нестандартная ниша» |
| 2 | Параметры | Один экран, форма из 3 блоков. Тип мебели — радиокнопки-плитки с иконками (шкаф / гостиная / прихожая / спальня / детская / кухня / другое). Размеры: 3 поля с «мм» и подсказкой «Можно примерно» |
| 3 | Фото | Drag-and-drop или «Выбрать файл». Пояснение: «Фото комнаты/плана ускорит просчёт. Можно без него» |
| 4 | Контакты | Телефон (обязательно), имя (опционально). Галочка согласия на обработку данных, ссылка на политику |
| 5 | Отправка | Кнопка «Получить расчёт». Валидация: телефон в формате +7 (9хх) ххх-хх-хх |
| 6 | Подтверждение | Экран успеха + опция «Дублировать в WhatsApp» (переход на wa.me) |

### Б.3 Mobile — отличия

1. **Вход:** таб-бар «Просчёт» — самая быстрая точка, минуя меню.
2. **Сокращение формы:** сначала **только телефон + кнопка «Перезвоните мне»** (вариант «Со своими размерами» раскрывает остальные поля). Идея: 86% звонков забивают на 5-польных формах.
3. **Фото:** через камеру прямо из формы («Снять фото комнаты») — нативные пикеры.
4. **Клавиатура:** поля размеров открывают цифровую клавиатуру (inputmode="numeric").
5. **Состояние успеха:** отдельный экран с чеком, а не тост; кнопки «Записать номер», «Написать в WhatsApp».

### Б.4 Состояния и риски сценария Б

| Состояние | UX-поведение |
|---|---|
| Невалидный телефон | Поле краснеет, подпись «Введите номер в формате +7 (900) 000-00-00»; кнопка остаётся активной (проверяем на submit) |
| Файл слишком большой | «Фото больше 10 МБ. Уменьшите или пришлём без него — это не обязательно» |
| Отправка (сеть) | Кнопка → «Отправляем…»; при сбое — «Не получилось отправить. Попробуйте ещё раз» и **пункт «Позвонить: +7 (920) 622-51-95»** |
| Менеджер не дозвонился | Автоматическое СМС «Не дозвонились. Напишите нам в WhatsApp, отвечаем 5 минут» — нивелируем потерю лида |
| Дубли ввод (honeypot на ботов) | Скрытое поле, спам-фильтр — без влияния на пользователя |

**Метрики:** конверсия форма→заявка ≥ 30%; заявка→просчёт ≥ 60%; доля просчёта из мобильного ≥ 50%; отказы на форме < 40%.

## 3. Общие правила обоих сценариев

1. **Ни один шаг не требует регистрации** (личный кабинет — после заказа, для трекинга).
2. **Цены и сроки показываются раньше, чем просят контакты** — снимает главную боль рынка.
3. **Каждое узкое место** (нестандартные размеры, отсутствие товара, ошибка формы) **переводит в сценарий Б** — это не тупик, а ветка продажи.
4. **Все обещания подкреплены:** «всё включено» расшифровывается; сроки сопровождаются трекингом; звонок за 15 минут — подкреплён таймером в UI подтверждения.
5. **Отмена/возврат читается до оплаты**: на этапе оформления ссылка «Условия возврата и отмены».
