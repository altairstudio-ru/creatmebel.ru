# Протокол UX-сессии — UX-фундамент прототипа «Креат Мебель» v2.0

**Дата:** 11.09.2026 | **Автор:** ArchitectUX | **Статус:** готово для UI-дизайнера

---

## Что сделано
Создан UX-фундамент для дизайн-прототипа (6 целевых страниц) на основе исследования рынка (`00-исследование-ландшафт-план.md`) и структуры старого сайта (`старый-сайт/структура-creatmebel-архив.md`).

## Артефакты
- `prototype/ux/site-map.md` — информационная архитектура, карта сайта, навигация (шапка / mobile / footer / mega-menu), упрощение категорий 26 → 11.
- `prototype/ux/user-flows.md` — сценарии «купить диван» и «заказать просчёт по размерам» для desktop + mobile, со состояниями, рисками и метриками.
- `prototype/ux/wireframes.md` — low-fi вайрфреймы всех 6 страниц (mobile-first), состояния (empty/error/loading/hover/active).
- `prototype/ux/content-requirements.md` — требования к контенту по блокам: заголовки, цены, сроки, гарантии, тон, SEO; открытые вопросы заказчику.

## Ключевые решения
1. Каталог: 2 суперкатегории (Мягкая/Корпусная), 11 подкатегорий, узкие разделы старого сайта → фильтры (диваны прямые/угловые/детские = фильтр типа).
2. Принцип «не 5-польная форма, а ветка продажи»: каждое узкое место (нет товара, нестандартный размер, ошибка) переводит в сценарий «просчёт по размерам».
3. Mobile: нижний таб-бар с 5-м пунктом «Просчёт» (вторая воронка продаж), sticky-панель покупки на карточке товара.
4. Прозрачность как UX-паттерн: «цена всё включено» расшифровывается, честные тарифы доставки без «от 500 ₽», сроки + трекинг на каждом этапе.
5. Формат цен/сроков единый; телефон один +7 (920) 622-51-95; Москва в H1/SEO.
