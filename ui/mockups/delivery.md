## 2. Калькулятор доставки + таблица тарифов

**Левая колонка (калькулятор, 1/2 ширины) / правая (таблица, 1/2).**

### 2.1. Калькулятор

**H2:** «Рассчитайте доставку» (якорь `#calculator`).

Поля:
1. `Город` — select: Москва (по умолчанию). Другие города → блок «Доставка по России» (ссылка на ТК, открытый вопрос — для M1 «Москва и МО»).
2. `Расстояние` — чипы: `В пределах МКАД` [active] / `За МКАД: [км]` (number, `inputmode="numeric"`, min 1, max 100).
3. `Этаж` — number (1–25), placeholder «1».
4. `Лифт` — чипы: `Лифт есть` [active] · `Лифта нет` (при выборе «нет» появляется строка «Подъём без лифта — 350 ₽/этаж»).
5. `Сборка` — чипы: `Не нужна` [active] · `Собрать самим` → не показываем, у нас вкл. · хм, правильнее: `Нужна (диван — в подарок)` → `Сборка в подарок на диваны` · `На корпусную: 500–1 500 ₽`.

**Результат (живой, без кнопки «рассчитать»):**
```
─────────────
Доставка и подъём:  Включено бесплатно   ← оливковый
Сборка:             0 ₽ (в подарок)
─────────────
Итого:              0 ₽ — всё включено
─────────────
```
Анимация числа 200ms при изменении. Крупный блок `--radius-lg`, фон `--color-success-soft`, текст оливковый-700.

Под результатом caption: «Точную стоимость подтвердим при заказе. За МКАД дальше 50 км — индивидуальный расчёт.»

**Состояния:**
| | |
|---|---|
| `[error]` км | поле `.is-error`, подпись «Укажите расстояние» (только цифры) |
| За МКАД > 50 км | баннер `--color-warning-soft`: «Доставка за МКАД свыше 50 км — индивидуальный расчёт [Оставить заявку]» (`data-src="delivery-anomaly"`) |
| Неизвестный тариф | в таблице ячейка «Уточняется при подтверждении заказа» — никогда не прячем цену молчанием |

**Классы:** `.range` не нужен; `.chip`, `.input`, `.field`, `.result-box`

## 5. FAQ (аккордеон)

**H2:** «Частые вопросы»

6 вопросов (контент по content-requirements §5, тексты копирайтеру):

1. **«Можно ли вернуть мебель?»** — Да, в течение 7 дней, если товар не подошёл и не был в эксплуатации. Расскажем процесс и заберём.
2. **«Что, если не подошло по размерам?»** — До заказа — замер/консультация и схемы с габаритами; после получения — возврат 7 дней. А лучше — закажите просчёт по своим размерам.
3. **«Как отменить заказ?»** — До запуска производства — бесплатно, одним сообщением. После — по договору.
4. **«Не влезает в грузовой лифт / дверь?»** — Согласуем до доставки: разборные модули, подъём через окно, замерим проёмы заранее.
5. **«Какие сроки, если я заказал под размер?»** — Шкаф под размер — 10–14 дней, +1–2 дня доставка. Статус — по СМС.
6. **«Что, если вы не дозвонитесь?»** — Пришлём СМС «Не дозвонились» и продублируем в WhatsApp. Отвечаем 5 минут в рабочее время.

**Классы:** `.acc` (ДС §6.13). Mobile: заголовки 16px, панели раскрываются тапом.
