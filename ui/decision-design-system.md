# Решение: Design System для creatmebel.ru v2.0

**Дата:** 11.09.2026
**Статус:** утверждено заказчиком

## Выбор

**shadcn/ui + Tailwind-токены** (вариант «A», рекомендованный)

## Обоснование

1. **Заказчик уже использует shadcn/ui** на своём сайте → единая система и стек, унификация между проектами.
2. **Полная кастомизация темы** через CSS-переменные (shadcn работает на Tailwind-токенах) → палитра «Тёплый сервисный минимализм» ложится 1:1.
3. **Набор компонентов** покрывает все нужды e-commerce: dialog/bottom sheet (шторки фильтров), tabs, accordion, forms, skeleton, toast.
4. **A11y на уровне Radix** — доступность из коробки.
5. **Переносимость**: прототип на статике использует те же токены, что и будущий продакшн на shadcn/ui → минимум переделок.

## Реализация в прототипе

- Статический сайт: чистый HTML/CSS с Tailwind v4
- Токены: `prototype/src/input.css` (`@theme` + компонентные классы: `.btn-*`, `.card`, `.chip`, `.tab`, `.badge`, `.field`)
- Сборка: `npm run build:css` → `assets/css/main.css`
- На продакшене токены и классы переносятся в shadcn/ui компоненты (Button, Card, Tabs, Sheet, Accordion, Form...)

## Связь с дизайн-системой

Кастомные классы `.btn-*`, `.card`, `.chip`, `.tab`, `.badge`, `.field`, `.skeleton`, `.included-icon` соответствуют компонентам из `prototype/ui/design-system.md` и макетируются в shadcn/ui компоненты на этапе продакшена.

## Отклонённые альтернативы

| Система | Причина отклонения |
|---------|-------------------|
| Tailwind custom (без shadcn) | Дублирует работу, нет готовых примитивов a11y |
| Material Design 3 | «Гугловский» стиль, сложно к тёплому интерьерному минимализму |
| Radix UI (чистый) | Отсутствие декларативного слоя, весь UI-кит писать руками |
| Ant Design / Mantine | Корпоративный стиль, не совпадает со стеком заказчика |
