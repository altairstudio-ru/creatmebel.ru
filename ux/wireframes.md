# Креат Мебель v2.0 — Low-fi вайрфреймы (mobile-first)

**Дата:** 11.09.2026 | **Автор:** ArchitectUX | **Статус:** для UI-дизайнера

---

## 0. Общая сетка и принципы

- **Mobile (320–767px):** базовая сетка — 4 колонки, отступы по краям 16px, вертикальный ритм 8px.
- **Desktop (≥1024px):** 12 колонок, контейнер 1280px, отступы 32px.
- **Обозначения состояния** используются на каждой странице:
  - `[hover]` — hover/focus (desktop) или tap (mobile);
  - `[empty]` — пустое состояние;
  - `[error]` — ошибка ввода/загрузки;
  - `[loading]` — скелетон;
  - `[active]` — выбранный элемент (вкладка, фильтр, опция).
- Все интерактивные блоки ≥44×44px (зона касания), фокус-обводка 2px.
- Шапка: см. `site-map.md` — desktop menu / mobile burger + нижний таб-бар.

### Состояния

| Состояние | Поведение |
|---|---|
| `[empty]` фильтр | Карточка-заглушка: «Под эти параметры ничего нет» → [Сбросить фильтры] + [Сделаем по вашим размерам] |

| Товар снят с продажи | Плашка «Архив»/«Нет в наличии» серая, карточка некликабельна, вместо цены — «Сообщить о поступлении» |

```
│ ФОРМА «Остались вопросы?» (имя/телефон/вопрос)              │
├──────────────────────────────────────────────────────────────┤
│ FOOTER                                                       │
└──────────────────────────────────────────────────────────────┘
```

### Mobile

```
[Шапка | H1 | [Заказать звонок] крупно | таб-бар]

```

### Состояния

| Состояние | Поведение |
|---|---|
| Форма `[error]` | Подсветка полей, точные подсказки (телефон/email) |
| `[success]` отправки | «Спасибо! Ответим в течение 15 минут в рабочее время» + [Написать в WhatsApp] |
| Вне часов работы | Блок «Сейчас закрыто. Откроется завтра в 9:00» + переход на форму оставления заявки |
| Карта `[loading]` | Скелетон + плашка «Загружаем карту…»; `[error]` — адрес текстом и кнопка «Открыть в Яндекс.Картах» |
| `[hover]` тап-зон | Desktop: изменение фона; mobile: состояние pressed (затемнение) |

## 7. Чек-лист для UI-дизайнера

- [ ] Все `[active]` состояния на чипах/табах контрастны (терракота #C25E3C или оливковый #7A8450).
- [ ] Пустые состояния — не «ничего», а ветка в сценарий Б (просчёт по размерам).
- [ ] Скелетоны вместо спиннеров в каталоге и галерее.
- [ ] Sticky-панель на карточке товара на mobile не перекрывает нижний таб-бар (между ними безопасный отступ).
- [ ] Все кнопки с текстом действия (не «OK»); у форм — заголовки и пояснения до полей.
- [ ] Калькулятор доставки считает без кнопки «рассчитать».
- [ ] Числа и юниты («₽», «мм», «дней») — один формат по всему сайту (настраивается в дизайн-токенах).
