## 4. Десктоп: сайдбар фильтров (280px) + список

### 4.1. Левая панель (≥1024)

```
[Фильтры]
Тип:
  ☑ Прямые   ☐ Угловые   ☐ Детские
Цена до:
  [────●──────────] 60 000 ₽
Механизм:
  ☐ еврокнижка  ☐ аккордеон  ☐ клик-кляк  ☐ выкатной
Материал:
  ☐ ткань  ☐ экокожа  ☐ велюр  ☐ рогожка
[Показать 14 диванов]   [Сбросить]
─────────────
[⚡ Мебель по вашим размерам — баннер mini]
```

- Чекбоксы кастомные (ДС §6.4 `.check`).
- Ползунок `.range` (ДС §6.20), диапазон до 60 000 ₽, значение живёт в `output`.
- Кнопка «Показать 14 диванов» — `--primary --full`; «Сбросить» — ghost (справа/под ней текст-ссылка).
- Баннер-мини: прямая ссылка в сценарий просчёта, фон `--color-terra-50`, `data-src="catalog-filters"`.
- **Сайдбар липкий** (`position: sticky; top: 88px`), высота ≤ viewport со своим скроллом при overflow.

### 4.2. Список (правая часть)

**Строка-суммари:** `Найдено 14 диванов` (Manrope 600, обновляется при фильтрах) … `Сортировка: [по популярности ▾]` (select-кастомный).

**Сетка карточек:** 3 колонки `repeat(3, 1fr)`, gap 24px. Карточки `--card-product` (ДС §6.2).

### 4.3. Состояния сетки

| Состояние | Поведение |
|---|---|
| `[loading]` | скелетоны `.skeleton-card` (заполняют 3 колонки), текст кнопки «Загружаем…» |
| `[empty]` | `.empty` (ДС §6.15): «Под эти параметры ничего нет» + `[Сделаем по вашим размерам]` (primary, `data-src="empty-catalog"`) + `[Сбросить фильтры]` |
| `[error]` сеть | баннер сверху сетки: «Не получилось загрузить. [Обновить]» (`--color-error-soft` фон), под ним — кешированный список карточек с пометкой «показаны сохранённые» |
| `is-archive` | карточка серые, «Нет в наличии» вместо цены → кнопка «Сообщить о поступлении» |

## 5. Mobile (<1024)

```
[H1 «Каталог»]
[Табы: Мягкая | Корпусная]
[Чипы подкатегорий ← Диваны | Кресла | Кровати →]   (лента, свайп)
[⚙ Фильтры (2)]  [Сортировка: по популярности ▾]
[Карточки 2 колонки]
[Показать ещё (full)]
[Нижний таб-бар]
```

- **Карточка мобильная:** фото 4:3, название 15px (2 строки), цена `--fs-price-m` + срок оливковым, кнопка-иконка «В корзину» вместо full-кнопки (тач 44×44, терракотовый круг, иконка корзины) + тост при добавлении.
- **Фильтры → шторка** (ДС §6.5 `.dialog--sheet`):
  - Секции: Тип (чипы, мультивыбор), Цена до (range), Механизм (чипы), Материал (чипы).
  - Футер шторки: `[Сбросить]` … `[Показать 14 товаров]` (primary).
  - Счётчик в кнопке «Фильтры (N)» растёт при выборе.
- **Сортировка:** нативный `select` внутри строки действий; вариант «по возрастанию цены» полезен для ценового сегмента.

**Мобильные акценты по контенту:**
- Первый экран без скролла: H1 + табы + чипы. Строки действий и карточки — второй экран.
- Скрываем на mobile: баннер «Мебель по вашим размерам» в сайдбаре (остаётся в таб-баре «Просчёт»).
- Показываем: количество «Найдено 14» строкой над карточками (небольшая, caption).

## 6. Корпусная мебель (короткое описание для прототипа)

Те же компоненты, другие фильтры:
- **Фильтры:** Цена до 60 000 ₽, Материал (ЛДСП/МДФ/массив), Цвет (чипы-палитра: дуб молочный `#D8C9AE`, дуб графит `#4A4440`, серый камень `#B9B3AC` и т.п.), Габариты (Ш см range).
- Подкатегории-чипы: Шкафы (18), Гостиная (14), Прихожая (10), Спальня (12), Детская (10), Кухня (12).
- Пример карточек: Шкаф-купе «Премиум-3» **57 300 ₽** (10–14 дней), Прихожая «Малевич-5» **31 500 ₽**, Кровать «Фокус» **29 100 ₽** (Мягкие кровати остаются в мягкой), Гостиная «Соло-9» **30 200 ₽**, Комод «Стрит-3» **30 400 ₽**, Кровать «Тренто-1» **31 700 ₽**.

## 7. Состояния и переходы (сводка)

| Событие | Поведение | Токены |

| «Показать ещё» | +6–9 карточек, lazy-load фото | `.card-product` |
