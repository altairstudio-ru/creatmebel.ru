## Как пользоваться

1. **Вёрстка.** Сначала перенести токены из `design-system.md` §2 в `:root`, затем компоненты §6 (HTML+CSS), затем страницы из макетов: классы из макетов ссылаются на готовые компоненты.
2. **Контент.** Тексты в макетах — финальные для прототипа, но требуют подтверждения количественных цифр (цены, тарифы, рассрочка) — см. список ниже.
3. **Состояния.** В каждом макете есть таблица состояний; обязательные для реализации в M1: скелетоны (каталог/галерея/карта), empty→просчёт, error форм, sticky-панель, тост корзины.
4. **Мобильные акценты** выделены в каждом макете блоком «Mobile» / «Mobile-порядок».

## Сквозные решения (поверх вайрфреймов)

1. **Палитра** закреплена в токенах: молочный фон `#F8F5F0`, песочный `#EFE7DA`, терракота `#C25E3C` — только CTA/активы, оливковый `#7A8450` — «включено/гарантии», синий `#2E4152` — доверие/сервис/справка.
2. **Кнопка «В корзину» на карточке всегда видима** (в вайрфрейме она «появлялась» по hover). Решение осознанное: не прятать действие покупки — конверсия важнее «чистоты» каталога.
3. **Цифра рассрочки пересчитана**: 45 200 ₽ / 4 = 11 300 ₽/мес (в вайрфреймах стояло 3 767₽ — равно 45 200/12; вопрос заказчику).
4. **Бейдж на карточке — один** («−5 000 ₽» вместо «Хит» при наличии выгоды), по требованию контента «не более одной метки».
5. **Сайдбар фильтров** на desktop липкий; на mobile фильтры живут в нижней шторке с футером `[Сбросить] [Показать N]`.

## Открытые вопросы для заказчика (влияют на данные макетов)

- [ ] Тарифы за МКАД (40 ₽/км?), подъём без лифта (350 ₽/этаж?), сборка корпусной (500–1 500 ₽).
- [ ] Условия рассрочки: срок (4 или 12 мес), мин. сумма, банки.
- [ ] Цифры «о нас»: 2 000+ заказов, 98% в срок — подтвердить.
- [ ] Адрес шоурума/производства и реквизиты.
- [ ] Скидки: «−5 000 ₽» на «Ричардс» и остальные из архива — актуальны ли на дату прототипа.
