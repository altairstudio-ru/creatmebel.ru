# Креат Мебель v2.0 — Информационная архитектура и карта сайта

**Дата:** 11.09.2026 | **Автор:** ArchitectUX | **Статус:** черновик для UI-дизайнера и разработчика

---

## 1. Принципы упрощения каталога

Старый сайт имел **26 узких категорий** (10 мягких + 16 корпусных) и продавал «всё подряд». Это размывало фокус и заставляло пользователя делать лишние клики. Для прототипа (M1, 200–400 SKU) вводим **двухуровневую структуру**: 2 суперкатегории → 11 подкатегорий → атрибуты-фильтры вместо отдельных разделов.

**Правило прототипа:** в подкатегории — не больше 12–24 SKU для демо. Хорошие 6 карточек на экране важнее «полки из 200 товаров».

| Категория старого сайта | Куда переехала в v2.0 |
|---|---|
| Прямые / угловые / детские диваны | Подкатегория **«Диваны»** + фильтр по типу конструкции |
| Кушетки, кухонные, офисные диваны | **Убраны из прототипа** (низкая конверсия, узкий спрос) |
| Кресла, пуфики | Подкатегория **«Кресла и пуфики»** |
| Кровати мягкие | Подкатегория **«Мягкие кровати»** |
| Стулья, табуреты | **Убраны из прототипа** (идут с кухнями/обеденными группами в M2) |
| Шкафы-купе / распашные / гармошки / угловые | Подкатегория **«Шкафы»** + фильтр по типу дверей |
| Стенки, комоды, ТВ-тумбы, столики | Подкатегория **«Гостиная»** |
| Прихожие, обувницы | Подкатегория **«Прихожая»** |
| Спальни, кровати ЛДСП, тумбы, туалетные столики | Подкатегория **«Спальня»** |
| Детский гарнитур, комоды, кровати | Подкатегория **«Детская»** |
| Кухни, обеденные группы | Подкатегория **«Кухня»** |
| Офисная мебель, серии-комплекты, материалы | **Вынесены за прототип** (M2+ / отдельные страницы-лендинги) |

## 2. Карта сайта (6 целевых страниц)

```
creatmebel.ru
│
├── /                          Главная
│     └── ведёт на: Каталог, Карточку товара, Производство, Доставка, Контакты,
│                   форму «Мебель по вашим размерам»
│
├── /catalog/                  Каталог
│     ├── /catalog/myagkaya/   (вкладка Мягкая мебель)
│     │     ├── /catalog/myagkaya/divany/          Диваны (+фильтры: прямой/угловой/детский)
│     │     ├── /catalog/myagkaya/kresla/          Кресла и пуфики
│     │     └── /catalog/myagkaya/krovati/         Мягкие кровати
│     ├── /catalog/korpusnaya/ (вкладка Корпусная мебель)
│     │     ├── /catalog/korpusnaya/shkafy/        Шкафы
│     │     ├── /catalog/korpusnaya/gostinaya/     Гостиная
│     │     ├── /catalog/korpusnaya/prihozhaya/    Прихожая
│     │     ├── /catalog/korpusnaya/spalnya/       Спальня
│     │     ├── /catalog/korpusnaya/detskaya/      Детская
│     │     └── /catalog/korpusnaya/kuhnya/        Кухня
│     └── ?f=...               (активные фильтры — в URL, чтобы можно было шарить)
│
├── /product/{slug}/           Карточка товара (динамическая)
│
├── /o-nas/                    Производство и о нас
│
├── /dostavka-i-oplata/        Доставка и оплата
│
└── /kontakty/                 Контакты
```

**Служебные страницы вне прототипа (но будут в M1):** корзина, оформление заказа, подтверждение заказа, «спасибо» + трекинг. В прототипе они реализуются как модальные/переходные состояния, чтобы показать воронку целиком.

## 3. Навигация

### 3.1 Шапка (desktop, ≥1024px)

```
┌────────────────────────────────────────────────────────────────────────────┐
│ Логотип │ Каталог ▾ │ Производство │ Доставка и оплата │ Контакты │ ☎ │ 🛒 │
│         │           │              │                   │          │  9  │
└────────────────────────────────────────────────────────────────────────────┘
```

- Первичные пункты: **Каталог** (главный), Производство, Доставка и оплата, Контакты.
- Справа: **телефон** +7 (920) 622-51-95 (на desktop показан целиком, клик = обратный звонок), **корзина** со счётчиком.
- «Каталог» — раскрывающаяся панель с 2 колонками суперкатегорий и подкатегорий (см. п. 3.4).
- Липкая шапка с «лёгкой тенью» при скролле. На карточке товара (mobile) шапка сжимается, появляется sticky-бар покупки.

### 3.2 Мобильная навигация (320–767px)

**Верхняя строка:** логотип + телефон (компактно) + корзина + бургер.

**Нижний таб-бар** (рекомендован для прототипа — 5 точек касания, большой палец):

```
┌────────────────────────────────────┐
│  Главная   Каталог     🛒    Просчёт  Контакты  │
│  (дом)     (кат.)   (корзина) (рулетка)(теле)    │
└────────────────────────────────────┘
```

- Таб-бар фиксирован снизу, высота 56–64px, безопасная зона iOS.
- Пункт **«Просчёт»** — быстрый вход в форму «Мебель по вашим размерам» (наш второй сценарий, ключевой для корпусной мебели).
- При скролле каталога/карточки таб-бар остаётся; в карточке товара снизу появляется преимущество перед таб-баром — **sticky-кнопка «Добавить в корзину»**.

### 3.3 Футер (desktop + mobile)

```
┌────────────────────────────────────────────────────────────┐
│ [Логотип + 1 строка про производителя]                      │
│                                                             │
│ Каталог        Покупателям         Контакты                 │
│  Мягкая мебель  Доставка и оплата   +7 (920) 622-51-95      │
│  Корпусная      Производство         info@creatmebel.ru     │
│  мебель         Гарантия*           Москва                  │
│                 Как заказать*       WhatsApp VK OK          │
│                 Просчёт по размерам 9:00–20:00              │
│                                                             │
│ © 2025–2026 КРЕАТМЕБЕЛЬ · Политика конфиденциальности       │
└────────────────────────────────────────────────────────────┘
```
*Гарантия и «Как заказать» — отдельные страницы M2; в прототипе — якоря на страницах Доставка/Карточка.

### 3.4 Панель «Каталог» (mega-menu)

```
┌─ Каталог ────────────────────────────────────────────────┐
│  МЯГКАЯ МЕБЕЛЬ            КОРПУСНАЯ МЕБЕЛЬ                │
│  ▸ Диваны (12)            ▸ Шкафы (18)                    │
│    · прямые · угловые     ▸ Гостиная (14)                 │
│    · детские              ▸ Прихожая (10)                 │
│  ▸ Кресла и пуфики (6)    ▸ Спальня (12)                  │
│  ▸ Мягкие кровати (8)     ▸ Детская (10)                  │
│                           ▸ Кухня (12)                    │
│  ────────────────────────────────────────────────         │
│  ⚡ Мебель по вашим размерам → просчёт за 15 минут        │
└───────────────────────────────────────────────────────────┘
```

В скобках — число SKU (почему их показываем: снижает страх «пустого каталога» и помогает оценить ширину ассортимента).

### 3.5 Хлебные крошки

Формат: `Главная / Каталог / Мягкая мебель / Диваны / Диван «Ричардс»`. На mobile крошки ужимаются в одну строку, точка входа — «Диваны» или суперкатегория.

## 4. Правила навигации (UX-ограничения)

1. **Не больше 4 пунктов в шапке.** Всё, что не входит в топ-4, — в футере или mega-menu.
2. **Каталог всегда доступен в 1 клик** с любой страницы (шапка + таб-бар).
3. **Каждый путь к покупке ≤ 3 кликов** от главной: Главная → Каталог → Карточка.
4. **Телефон и контакты видны на каждой странице** (это сервисный магазин, консультация — часть УТП).
5. **Вход в «Просчёт по размерам»** доступен из 4 точек: mega-menu, главная (баннер), карточка товара, таб-бар mobile. Это второй сценарий продажи — он не должен быть спрятан.
